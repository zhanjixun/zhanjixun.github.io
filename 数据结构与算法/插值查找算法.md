# 插值查找算法

## 算法思想

插值查找（Interpolation Search）类似于二分查找算法，不同的是插值查找每次从自适应 mid 处开始查找。插值查找算法的代码过程跟二分查找十分相像，唯一不同的就是`mid`值的计算。其中二分查找的mid计算公式是：
$$
mid=\frac{low+high}{2}=low+\frac{1}{2}(high-low)
$$


而插值查找算法的mid计算公式是：
$$
mid=low+\frac{key-arr[low]}{arr[high]-arr[low]}(high-low)
$$


插值查找算法相比于二分查找算法：

1、对于数据`分布均匀`的查找表而言，速度更快

2、数据分布不均匀的查找表，速度不如二分查找

## 代码实现

```java
public static int insertValueSearch(int[] arr, int left, int right, int findVal) { 
	//注意：findVal < arr[0]  和  findVal > arr[arr.length - 1] 必须需要
	//否则我们得到的 mid 可能越界
	if (left > right || findVal < arr[left] || findVal > arr[right]) {
		return -1;
	}
	// 求出mid, 自适应
	int mid = left + (right - left) * (findVal - arr[left]) / (arr[right] - arr[left]);
	int midVal = arr[mid];
    // 说明应该向右边递归
	if (findVal > midVal) { 
		return insertValueSearch(arr, mid + 1, right, findVal);
	} 
    // 说明向左递归查找
    if (findVal < midVal) { 
		return insertValueSearch(arr, left, mid - 1, findVal);
	} 
	return mid;
}
```
