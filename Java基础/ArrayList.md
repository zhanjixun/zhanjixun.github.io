# 基于数组实现的集合类ArrayList

> ArrayList有用过吗？它是一个什么东西？可以用来干嘛？

有用过，ArrayList是**基于数组实现**的列表，它的主要底层实现是数组Object[] elementData。与它类似的是LinkedList，和LinkedList相比，它的查找和访问元素的速度较快，但新增，删除的速度较慢。

特点：**基于数组实现**、**访问速度较快**、**增删速度较慢**

> 为啥线程 不安全还使用他呢？

因为在平时使用中，都是用来查询，不会过频繁的增删。如果涉及频繁的增删，可以使用LinkedList。如果需要线程安全，则可以使用Vector。
