# Redis实现分布式锁

在Redis中可以使用SETNX命令实现分布式锁，原理是当key不存在时候才设置，否则不设置。

| 问题                              | 描述               | 解决方案                                     |
| --------------------------------- | ------------------ | -------------------------------------------- |
| 不可重入性                        |                    | 1.ThreadLocal <br>2.Redis Hash<br>3.Redisson |
| 锁过期                            | 锁超时，任务未完成 | 1.锁续期<br>2.Redisson                       |
| 误删其他客户端的锁                |                    | value存唯一标识，校验一致再释放              |
| 单节点故障/主从复制失败导致锁丢失 |                    | Redlock 算法                                 |
