# 线性查找算法

## 说明

线性查找适合于存储结构为顺序存储或链接存储的线性表。 

## 算法思想

对于一个顺序储存的数据，线性查找就是从这顺序数据的头开始遍历到尾，如何匹配到数据就说明查找到了，如果没有则返回没有查找到数据。 

## 代码实现

```java
public int seqSearch(int[] arr, int value) {
    for (int i = 0; i < arr.length; i++) {
        if (arr[i] == value) {
            return i;
        }
    }
    return -1;
}
```

## 时间复杂度

查找成功时的平均查找长度为：（假设每个数据元素的概率相等） ASL = 1/n(1+2+3+…+n) = (n+1)/2 ; 
当查找不成功时，需要n+1次比较，时间复杂度为O(n); 
所以，顺序查找的时间复杂度为$O(n)$。
