# 秒杀系统的实现

## 分离部署

独立部署秒杀系统，使其与其他系统完全隔离

## 动静分离

商品页面静态化设计



### 对现有业务的冲击

解决方案：独立部署秒杀系统，使其与系统完全隔离。

### 高并发下应用和数据的负载

解决方案：重新设计静态化的商品页面，使前端页面刷新不需要经过应用服务器。

### 突然增加的网络及服务器带宽问题

解决方案：增加网络带宽，使用`动静分离`，将商品页面缓存在`CDN`中。

### 防止破解和提前下单

解决方案：`隐藏秒杀URL`或者将URL动态化，只有在秒杀开始时才能得到。

### 减库存的操作

解决方案：一种是`拍下扣减库存`，一种是`付款扣减库存`。推荐使用`拍下扣减库存`。

### 如何防止超卖问题

解决方案：使用`乐观锁`或者`尝试扣减库存`方式。

乐观锁：

```sql
update auction_auctions set
quantity = #inQuantity#
where auction_id = #itemId# and quantity = #dbQuantity#
```

尝试扣减库存：

```sql
update auction_auctions set
quantity = quantity-#count#
where auction_id = #itemId# and quantity >= #count#
```
