# Java运算符

运算符是对常量或者变量进行操作的符号，Java的运算符有六类：算数运算符、赋值运算符、关系运算符、逻辑运算符、三元运算符和位运算符，用运算符把常量或者变量连接起来符合java语法的式子称为**表达式**。

## 算数运算符

**基本运算**：`+`（加）、`-`（减）、`*`（乘）、`/`（除）、`%`（取模）

**自增/自减**：`++`（自增）、`--`（自减）

> 示例：`a++`（先取值后加1）和`++a`（先加1后取值）

## 赋值运算符

**简单赋值**：`=`

**复合赋值**：`+=`、`-=`、`*=`、`/=`、`%=`、`&=`、`|=`、`^=`、`<<=`、`>>=`、`>>>=`

> 示例：`a += 5; // 等价于 a = a + 5`

## 关系运算符

**比较操作**：`==`（等于）、`!=`（不等于）、`>`（大于）、`<`（小于）、`>=`（大于等于）、`<=`（小于等于）

## 逻辑运算符

**布尔逻辑**：`&&`（逻辑与，短路）、`||`（逻辑或，短路）、`!`（逻辑非）

**非短路逻辑**：`&`（逻辑与，非短路）、`|`（逻辑或，非短路）、`^`（逻辑异或）。

> 示例：`if (false & (x > 0))`（始终计算两边）

### 条件运算符（三元运算符）

**语法**：`条件 ? 表达式1 : 表达式2`

> 示例：`int max = (a > b) ? a : b;`

### 位运算符

**位操作**：`&`（按位与）、`|`（按位或）、`^`（按位异或）、`~`（按位取反）

> 示例：`int e = 5 & 3; // 结果1`

**位移操作**：`<<`（左移）、`>>`（带符号右移）、`>>>`（无符号右移）

> 示例：`8 << 1`结果为16

### 运算符优先级与注意事项

**优先级**：括号`()` > 一元运算符（如`++`） > 算术 > 位移 > 关系 > 逻辑/位 > 条件 > 赋值

**短路行为**：`&&`和`||`可能跳过右侧表达式

**类型转换**：复合赋值运算符自动转换类型（如`+=`可能隐式转型）
