# 布隆过滤器

布隆过滤器（Bloom Filter）是一种**高效判断元素是否存在集合中**的概率型数据结构。它的特点是：

1. 判断元素不存在，则元素**一定不存在**
2. 判断元素存在，元素**可能存在**也可能不存在

## 实现原理

布隆过滤器的核心是**用多个哈希函数映射到一个位数组（bit array）**。

假设我们有一个长度为 *m* 的位数组（初始都为 0），以及 *k* 个不同的哈希函数。

1. 当插入一个元素时，经过这 *k* 个哈希函数分别计算哈希值，得到 *k* 个下标位置；
2. 把这 *k* 个位置的比特位都置为 1；
3. 当检查一个元素是否存在时，同样计算这 *k* 个哈希值，去检查那几个位置；
4. **只要有一个位置是 0，说明该元素一定不存在；如果全部都是 1，说明“可能存在”。**

## 为什么会误判

因为不同元素可能通过哈希函数映射到了同样的几个位置。
如果这几个位置恰好都被之前的其他元素置为 1，那布隆过滤器会“以为”这个新元素也存在。

这就是**假阳性（false positive）**。

例如：

- 集合里存了 {a, b, c}
- 现在查 “x”
- 哈希后发现它对应的位置全是 1
   → 布隆过滤器说“x 在集合里”，但其实它根本没插入过。

## 优缺点

**优点：**

- 占用空间极小；
- 插入、查询速度快；
- 适合大规模数据的存在性判断（如缓存穿透、爬虫 URL 去重、黑名单判断等）。

**缺点：**

- 存在一定误判率；
- 无法删除（除非用计数版）；
- 无法获取原始数据，只能判断“可能存在”。

## 代码示例

```java
//cn.hutool.bloomfilter.BitMapBloomFilter
BitMapBloomFilter bitMap = new BitMapBloomFilter(8);
bitMap.add("a");
bitMap.add("b");
bitMap.add("c");
System.out.println(bitMap.contains("a"));
System.out.println(bitMap.contains("a1"));
System.out.println(bitMap.contains("d"));
```

## Redis实现布隆过滤器

### Bitmap 实现布隆过滤器

布隆过滤器底层其实就是一个**位数组 (bit array)**：

- 对一个值进行多次哈希（不同种子），每次取一个位位置
- 将这些位置设为 1
- 查询时再次哈希并检查这些位是否都为 1

```java
import redis.clients.jedis.Jedis;
import com.google.common.hash.HashFunction;
import com.google.common.hash.Hashing;

import java.nio.charset.StandardCharsets;

public class RedisBitmapBloomFilter {
    private final Jedis jedis;
    private final String key;
    private final int bitSize;
    private final int hashCount;
    private final HashFunction[] hashFunctions;

    public RedisBitmapBloomFilter(String host, int port, String key, int bitSize, int hashCount) {
        this.jedis = new Jedis(host, port);
        this.key = key;
        this.bitSize = bitSize;
        this.hashCount = hashCount;
        this.hashFunctions = new HashFunction[hashCount];

        // 初始化不同种子的哈希函数
        for (int i = 0; i < hashCount; i++) {
            hashFunctions[i] = Hashing.murmur3_128(i);
        }
    }

    // 添加元素
    public void add(String value) {
        for (HashFunction f : hashFunctions) {
            int offset = Math.abs(f.hashString(value, StandardCharsets.UTF_8).asInt()) % bitSize;
            jedis.setbit(key, offset, true);
        }
    }

    // 判断是否存在
    public boolean mightContain(String value) {
        for (HashFunction f : hashFunctions) {
            int offset = Math.abs(f.hashString(value, StandardCharsets.UTF_8).asInt()) % bitSize;
            if (!jedis.getbit(key, offset)) {
                return false;
            }
        }
        return true;
    }

    public void close() {
        jedis.close();
    }

    public static void main(String[] args) {
        RedisBitmapBloomFilter bloom = new RedisBitmapBloomFilter("127.0.0.1", 6379, "bloom:user", 1_000_000, 5);

        bloom.add("user:1001");
        bloom.add("user:1002");

        System.out.println(bloom.mightContain("user:1001")); // true
        System.out.println(bloom.mightContain("user:9999")); // false

        bloom.close();
    }
}
```

### RedisBloom 模块实现布隆过滤器

Redis 官方提供了一个模块：**RedisBloom**，专门实现布隆过滤器。

```shell
docker run -p 6379:6379 --name redis-bloom redislabs/rebloom

# 连接进容器
BF.RESERVE my_bloom 0.01 1000000
# my_bloom：过滤器名称
# 0.01：误判率（1%）
# 1000000：预计插入的元素数量

# 添加元素
BF.ADD my_bloom user:1001
BF.ADD my_bloom user:1002

# 批量添加
BF.MADD my_bloom user:1 user:2 user:3
BF.MEXISTS my_bloom user:1 user:4

# 判断是否存在
BF.EXISTS my_bloom user:1001   # 返回 1
BF.EXISTS my_bloom user:9999   # 返回 0
```
