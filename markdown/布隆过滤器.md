# 布隆过滤器

布隆过滤器（Bloom Filter）是一个用来**快速判断某个元素是否存在于集合中**的数据结构。它的特点是：

1. 判断元素不存在，则元素**一定不存在**
2. 判断元素存在，元素**可能存在**也可能不存在

## 实现原理

布隆过滤器的核心是**用多个哈希函数映射到一个位数组（bit array）**。

假设我们有一个长度为 *m* 的位数组（初始都为 0），以及 *k* 个不同的哈希函数。

1. 当插入一个元素时，经过这 *k* 个哈希函数分别计算哈希值，得到 *k* 个下标位置；
2. 把这 *k* 个位置的比特位都置为 1；
3. 当检查一个元素是否存在时，同样计算这 *k* 个哈希值，去检查那几个位置；
4. **只要有一个位置是 0，说明该元素一定不存在；如果全部都是 1，说明“可能存在”。**

## 为什么会误判

因为不同元素可能通过哈希函数映射到了同样的几个位置。
如果这几个位置恰好都被之前的其他元素置为 1，那布隆过滤器会“以为”这个新元素也存在。

这就是**假阳性（false positive）**。

例如：

- 集合里存了 {a, b, c}
- 现在查 “x”
- 哈希后发现它对应的位置全是 1
   → 布隆过滤器说“x 在集合里”，但其实它根本没插入过。

## 优缺点

**优点：**

- 占用空间极小；
- 插入、查询速度快；
- 适合大规模数据的存在性判断（如缓存穿透、爬虫 URL 去重、黑名单判断等）。

**缺点：**

- 存在一定误判率；
- 无法删除（除非用计数版）；
- 无法获取原始数据，只能判断“可能存在”。

## 代码示例

```java
//cn.hutool.bloomfilter.BitMapBloomFilter
BitMapBloomFilter bitMap = new BitMapBloomFilter(8);
bitMap.add("a");
bitMap.add("b");
bitMap.add("c");
System.out.println(bitMap.contains("a"));
System.out.println(bitMap.contains("a1"));
System.out.println(bitMap.contains("d"));
```
