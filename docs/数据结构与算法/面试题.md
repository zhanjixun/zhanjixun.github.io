编写函数int bits(int i),返回i的二进制中有多少个1。比如bits(0)=0,bits(0xFF)=8,bits(0x100)=1。请勿使用 Integer.toBinaryString等外部方法）。

```java
public int bits(int num) {
    int sum = 0;
    while (num != 0) {
        sum = sum + num % 2;
        num = num / 2;
    }
    return sum;
}
```

编写函数int string2Integer(String str),完成将字符串转换为整数的操作。例如string2Integer("123")=123,string2Integer("-35")=35.

注：请自己实现这个转换算法，而不要尝试调用Integer.parseInt(Str)或者Integer.valueOf(str)等函数

```java
public int strToInt(String str) {
    int num = 0;
    for (int i = str.length() - 1, n = 0; i >= 0; i--, n++) {
        char c = str.charAt(i);
        if ((c - '0') > 9) {
            return 0;
        }
        if (c == '-') {
            return num;
        }
        num = num + (c - '0') * (int) Math.pow(10, n);
    }
    return num;
}
```

有两个已经排序好的整数数组arr1，arr2，请编写函数，返回一个新的排序数组，这个数组包括了这个两个数组的全部整数。要求：不要使用嵌套的循环结构。（请勿使用Arrays.sort或类似外部排序函数，而是自己实现这个排序过程）。例如：arr1=[1,5] arr2=[2,6] 返回的数组为[1,2,5,6]

```java
public static int[] mergeSorted(int[] arr1, int[] arr2) {
    int[] resultArr = new int[arr1.length + arr2.length];
    int p = 0;//用于标记数组a
    int q = 0;//用于标记数组b
    int i = 0;//用于标记数组c

    //两个数组都有元素时
    while (p < arr1.length && q < arr2.length) {
        if (arr1[p] < arr2[q]) {
            resultArr[i++] = arr1[p++];
        } else {
            resultArr[i++] = arr2[q++];
        }
    }
    //若arr1有剩余
    while (p < arr1.length) {
        resultArr[i++] = arr1[p++];
    }
    //若arr2有剩余
    while (q < arr2.length) {
        resultArr[i++] = arr2[q++];
    }    
    return resultArr;
}
```

有两个已经排序好的整数数组arr1,arr2，请编写函数，返回一个新排序数组，这个数组包括了这两个数组的相同整数。例如：arr1=[1,5,8,10] arr2=[2,5,6,8] ，返回的数组为[5,8]

```java
public int[] filterSame(int[] arr1, int[] arr2) {
    List<Integer> reslut = new ArrayList<>();
    for (int i = 0, j = 0; i < arr1.length && j < arr2.length; ) {
        if (arr1[i] < arr2[j]) {
            i++;
        } else if (arr2[j] < arr1[i]) {
            j++;
        } else if (arr1[i] == arr2[j]) {
            reslut.add(arr1[i]);
            i++;
            j++;
        }
    }
    return reslut.stream().mapToInt(d -> d).toArray();
}
```

有一个已排序的整数数组，但其中可能存在重复的数字，请编写函数，去除数组中的重复数据（重复数据保留1个），返回去重后的数组长度N，同时，原数组的前N个成员是去重后的结果。例如：unique(array=[1,2,2,3,3,3])=3，并返回后array的前3个成员为[1,2,3]。注：要求算法的空间复杂度为O(1)

```java
public int unique(int[] array) {
    int right = array.length;
    for (int i = 0; i + 1 < right; i++) {
        //当前元素跟下一元素不相同，将游标标到下一个
        int next = i + 1;
        if (array[i] != array[next]) {
            continue;
        }
        int moveCount = 0;
        while (next < right && array[i] == array[next]) {
            moveCount++;
            next++;
        }
        if (next >= right) {
            break;
        }
        //将找到的不重复的后面整体前移moveCount位
        System.arraycopy(array, next, array, i + 1, right - next);
        right -= moveCount;
    }
    //System.out.println(Arrays.toString(array));
    return right;
}
```



并发编程。请编写2个线程，线程1顺序输出1，3，5，....，99等奇数，每个数一行。线程2顺序输出2，4，6，....，100等偶数，每个数一行。最终的结果要求是输出为自然顺序：1，2，3，4，....，99，100。

```java
public static void main(String[] args) {
    Object monitor = new Object();
    new Thread(new EvenPrintTask(monitor)).start();
    new Thread(new OldPrintTask(monitor)).start();
}
//打印奇数线程
public class OldPrintTask implements Runnable {

    private final Object monitor;
    //奇数线程从1开始打印
    private int value = 1;

    public OldPrintTask(Object monitor) {
        this.monitor = monitor;
    }

    @Override
    public void run() {
        while (value < 100) {
            synchronized (monitor) {
                System.out.println(value);
                value += 2;
                monitor.notify();
                try {
                    monitor.wait();
                } catch (InterruptedException e) {
                    e.printStackTrace();
                }
            }
        }
    }
}
//打印偶数线程
public class EvenPrintTask implements Runnable {

    private final Object monitor;
    //偶数对象
    private int value = 0;

    public EvenPrintTask(Object monitor) {
        this.monitor = monitor;
    }

    @Override
    public void run() {
        while (value <= 100) {
            synchronized (monitor) {
                System.out.println(value);
                value += 2;
                monitor.notify();
                try {
                    monitor.wait();
                } catch (InterruptedException e) {
                    e.printStackTrace();
                }
            }
        }
    }
}
```
