# 二叉树的遍历方法

## 前序遍历

前序遍历（也叫先序遍历）首先访问根节点然后遍历左子树最后遍历右子树，在遍历左右子树时候，仍然先访问根节点然后遍历左子树最后遍历右子树。
若二叉树为空则结束返回，否则：

（1）访问根结点。

（2）前序遍历左子树。

（3）前序遍历右子树 。

遍历左右子树时仍然采用前序遍历方法。

定义树节点为`TreeNode`：

```java
public class TreeNode {

    private int value;

    private TreeNode left;

    private TreeNode right;

    public TreeNode(int value) {
        this.value = value;
    }

    //getter setter
}
```

递归方式前序遍历：

```java
public static void preOrderRe1(TreeNode biTree) {
    if (biTree == null) {
        return;
    }
    System.out.println(biTree.getValue());
    preOrderRe1(biTree.getLeft());
    preOrderRe1(biTree.getRight());
}
```

非递归方式前序遍历：

```java
public static void preOrderRe2(TreeNode tree) {
    Stack<TreeNode> stack = new Stack<>();
    TreeNode node = tree;
    while (node != null || !stack.empty()) {
        if (node != null) {
            System.out.print(node.getValue() + "->");
            stack.push(node);
            node = node.getLeft();//从左子树开始遍历
        } else {
            TreeNode tempNode = stack.pop();
            node = tempNode.getRight();//node为null 当前节点已无子节点
        }
    }
}
```

## 中序遍历

中序遍历首先遍历左子树然后访问根节点最后遍历右子树，遍历左右子树时候仍是先遍历左子树然后访问根节点最后遍历右子树。

若二叉树为空则结束返回，否则：

（1）前序遍历左子树。

（2）访问根结点。

（3）前序遍历右子树 。

遍历左右子树时仍然采用中序遍历方法。

递归方式中序遍历：

```java
public static void inOrderRe1(TreeNode biTree) {
    if (biTree == null) {
        return;
    }
    inOrderRe1(biTree.getLeft());
    System.out.print(biTree.getValue() + "->");
    inOrderRe1(biTree.getRight());
}
```

非递归方式中序遍历： 

```java
public static void inOrderRe2(TreeNode root) {
    Stack<TreeNode> stack = new Stack<>();
    TreeNode node = root;
    while (node != null || !stack.empty()) {
        if (node != null) {            
            stack.push(node);
            node = node.getLeft();
        } else {
            TreeNode tem = stack.pop();
            System.out.print(tem.getValue() + "->");
            node = tem.getRight();
        }
    }
}
```

## 后序遍历

后序遍历首先遍历左子树然后右子树最后访问根节点，遍历左右子树时候仍是先遍历左子树然后右子树最后访问根节点

若二叉树为空则结束返回，否则：

（1）前序遍历左子树。

（2）前序遍历右子树 。

（3）访问根结点。

遍历左右子树时仍然采用后序遍历方法。

递归方式中序遍历：

```java
public static void postOrderRe1(TreeNode biTree) {
    if (biTree == null) {
        return;
    }
    postOrderRe1(biTree.getLeft());
    postOrderRe1(biTree.getRight());
    System.out.println(biTree.getValue() + "->");
}
```

非递归方式遍历：

```java
private static void postOrderRe2(TreeNode treeNode) {
    Stack<TreeNode> stack = new Stack<>();
    stack.push(treeNode);

    TreeNode cur, pre = null;
    while (!stack.empty()) {
        cur = stack.peek();
        if ((cur.getLeft() == null && cur.getRight() == null) || (pre != null && (pre == cur.getLeft() || pre == cur.getRight()))) {
            System.out.print(cur.getValue() + "->");
            stack.pop();
            pre = cur;
        } else {
            if (cur.getRight() != null) {
                stack.push(cur.getRight());
            }
            if (cur.getLeft() != null) {
                stack.push(cur.getLeft());
            }
        }
    }
}
```

## 层级遍历

```java
public void levelTraverse(TreeNode root) {
    if (root == null) {
        return;
    }
    Queue<TreeNode> queue = new LinkedList<>();
    queue.add(root);

    while (!queue.isEmpty()) {
        TreeNode node = queue.poll();
        System.out.print(node.getValue() + "->");

        if (node.getLeft() != null) {
            queue.add(node.getLeft());
        }
        if (node.getRight() != null) {
            queue.add(node.getRight());
        }
    }
}
```
